## Built-in Tools

* [write_todos](https://docs.langchain.com/oss/python/langchain/tools#write-todos): Manage a structured task list for your current work session.

* [write_file](https://docs.langchain.com/oss/python/langchain/tools#write-file): Create and manage files in the workspace.

* [read_file](https://docs.langchain.com/oss/python/langchain/tools#read-file): Read the contents of a file in the workspace.

* [edit_file](https://docs.langchain.com/oss/python/langchain/tools#edit-file): Edit the contents of a file in the workspace.

* [delete](https://docs.langchain.com/oss/python/langchain/tools#delete): Delete a file or directory in the workspace.

* [glob](https://docs.langchain.com/oss/python/langchain/tools#glob): Find files matching a glob pattern in the workspace.

* [grep](https://docs.langchain.com/oss/python/langchain/tools#grep): Search for a literal text pattern across files in the workspace.

* [execute](https://docs.langchain.com/oss/python/langchain/tools#execute): Execute a shell command in an isolated sandbox.

* [task](https://docs.langchain.com/oss/python/langchain/tools#task): Launch an ephemeral subagent to handle a complex, multi-step task in an isolated context window.
