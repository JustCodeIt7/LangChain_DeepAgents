## Built-in Tools

* [write_todos](#write-todos): Manage and plan complex objectives.
* [write_file](#write-file): Create and manage files.
* [edit_file](#edit-file): Edit existing files.
* [read_file](#read-file): Read the contents of a file.
* [delete](#delete): Delete a file or directory.
* [glob](#glob): Find files matching a glob pattern.
* [grep](#grep): Search for a literal text pattern across files.
* [execute](#execute): Execute a shell command in an isolated sandbox.
* [task](#task): Launch an ephemeral subagent to handle a complex task.
* [ls](#ls): List all files in a directory.
