# Release Notes Skill

Turn a raw list of changes into release notes using the exact house style below.

## Required format

```
## vX.Y.Z — <one-line theme>

### Added
- <new capabilities>

### Fixed
- <bug fixes>

### Changed
- <behavior changes>
```

## Rules

1. Every bullet starts with a past-tense verb ("Added", "Fixed", "Renamed").
2. Every bullet ends with a period.
3. Omit any section that would be empty — never write "None".
4. Keep each bullet under 15 words.
5. End the notes with the line: `_Generated by the release-notes skill._`
